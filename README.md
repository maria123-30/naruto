# naruto
# Página Informativa: Naruto Uzumaki

Este projeto é uma página web informativa no formato de artigo digital sobre o personagem **Naruto Uzumaki**, desenvolvida como parte de um projeto prático de desenvolvimento web.

## 📌 Tema Escolhido
A jornada e evolução do personagem **Naruto Uzumaki**, abordando sua origem, habilidades principais, grandes conquistas e sua filosofia de vida.

## 🚀 Tecnologias Utilizadas
- **HTML5**: Estruturação semântica da página (`<header>`, `<nav>`, `<main>`, `<article>`, `<section>`, `<aside>`, `<footer>`).
- **CSS3**: Estilização, layout responsivo com CSS Grid e Flexbox, além de efeitos visuais `:hover`.
- **Git & GitHub**: Controle de versão e hospedagem do código.
- **GitHub Pages**: Publicação e hospedagem pública da aplicação.
